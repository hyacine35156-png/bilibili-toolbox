# B站工具箱 - 项目开发规则 (agent.md)

> 本文件记录B站工具箱项目的所有开发规则、业务约束和用户偏好，每次迭代前请阅读。

## 一、持久偏好规则

1. **版本号显示**：每次功能更新后，界面上必须显示版本号。
2. **交互前自检**：每次交互前都进行自检。
3. **打包规则**：打包exe时，若无明确指令要求上传网站，则不需要生成zip压缩包，只需生成exe并更新桌面快捷方式指向新exe。
4. **旧快捷方式清理**：更新exe版本后，必须删除旧版本的桌面快捷方式（如更新到v5.9.8时，删除v5.9.7.lnk），只保留最新版本的快捷方式。
5. **更新后自动打开**：每次更新打包完成后，自动打开新打包的exe程序，方便用户立即测试。

## 二、业务功能规则

### 卡密系统
- 卡密系统离线宽限期为 **1天**。
- 卡密剩余时间精确到 **分钟**。
- 卡密验证后删除本地 `data/card_auth.json`，下次可直接登录直到卡密过期。
- 卡密验证核心逻辑在 `card_verify.py`（已pyarmor加密），UI代码在 `main_gui_pro.py`（明文）。
- 卡密最多绑定设备数、封禁管理、备注、延长有效期等功能在管理后台维护。

### 账户管理
- exe最多添加 **8个账号**。
- 发送弹幕界面左侧用户选择需要持久化保存（修复过重启后消失的bug）。

### 抢码/看播
- 抢码间隔设为 **600ms 到 800ms**。
- 兑换码只能在 **兑换码页面导出**，抢码过程中不提取兑换码，避免占用线程。
- B站搜索活动直接搜游戏名（如"绝区零"），不搜完整活动名。

### 送礼
- 送礼次数默认 **0**。
- 无电池时直接 **禁用按钮**。

### 下载中心
- 下载软件不需要卡密验证，所有人都可下载。
- 历史版本只保留 v5.9.1（下载页）。
- 每次更新需预留更新内容展示空间。
- **网站版本更新规则**：zip上传网站时，将**网站上当前显示的最新版本**移入历史版本，当前新版本显示在首页。注意：是把网站上当前的最新版本移入历史，而不是把代码中的上一个版本移入历史。例如：网站当前最新版本是v5.9.3，现在更新到v5.9.8，则把v5.9.3移入历史版本，v5.9.8显示在首页（不是把v5.9.7移入历史）。
- 网站采用**切换页面模式（SPA单页应用）**，顶部导航点击不跳转URL，直接切换内容区域。

### 任务分类
- 直播里程碑分类改名为 **"直播里程碑（下半）"**。
- 特殊任务移入直播里程碑分类。

## 三、技术与打包规则

### 项目结构
- 主程序：`main_gui_pro.py`（Tkinter GUI，明文）
- 卡密验证：`card_verify.py`（pyarmor 9.2.7 加密，40KB）
- 图标：`app_icon.ico`（粉色播放按钮）
- 打包spec：`B站工具箱_v{版本}.spec`

### 打包环境
- Python路径：`C:\Users\15868\AppData\Local\Programs\Python\Python314\python.exe`
- 打包命令：`python -m PyInstaller --clean "B站工具箱_v{版本}.spec"`
- spec文件必须包含：
  - `datas=[('pyarmor_runtime_000000', 'pyarmor_runtime_000000')]`
  - `hiddenimports=['websocket', 'requests', 'pyarmor_runtime_000000', 'card_verify']`
  - `icon=['app_icon.ico']`
  - `name='B站工具箱_v{版本}'`

### 加密说明
- `card_verify.py` 已用 pyarmor 9.2.7 (trial) 加密。
- `main_gui_pro.py`（430KB）因 pyarmor 试用版单文件限制（约40KB）无法加密。
- 核心验证逻辑已加密保护，UI代码明文为可接受设计。

### 桌面快捷方式
- 桌面路径：`E:\虚拟c盘\`
- 快捷方式命名：`B站工具箱_v{版本}.lnk`
