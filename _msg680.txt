## 一、修复「已完成」状态显示（核心 bug）

### 根因
  ui/schedule.py 里两个标记完成的方法都把状态重置为「等待中」：

    def _mark_task_done_with_log(self, task, msg):
        """标记任务完成并写日志，状态重置为等待中（次日继续执行）"""
        task["status"] = "等待中"          <- 问题了这里
        ...

    def _mark_task_done(self, task):
        task["status"] = "等待中"          <- 同样问题

  导致任务明明执行完了（日志里有「✓ [日程] 弹幕任务「弹幕1」已完成」），
  但列表状态列仍显示「等待中」，用户误以为任务没执行。

### 修复
  改为显示「已完成」，并记录完成时间戳 last_done：

    def _mark_task_done_with_log(self, task, msg):
        task["status"] = "已完成"
        task["last_done"] = time.strftime("%m-%d %H:%M")
        ...

    def _mark_task_done(self, task):
        task["status"] = "已完成"
        task["last_done"] = time.strftime("%m-%d %H:%M")
        ...

  说明：调度器在次日到达触发时间时会重新把状态设为「等待中」再执行，
        所以不影响每日重复执行。

### 验证
  直接调用 _mark_task_done：
    原状态: 等待中
    调用后: 已完成          PASS
    完成时间: 10-30 19:53   PASS
  截图中「弹幕1」已正确显示绿色「已完成」
